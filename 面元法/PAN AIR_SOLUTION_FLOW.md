# PAN AIR 高阶面元法求解流程

## 概述

PAN AIR（Panel Aerodynamics）是波音公司开发的生产级高阶面元法程序，用于求解亚音速和超音速线性势流边值问题。本实现为 F90 移植版本（Version 15.0, 2009），代码集中在 `panair.f90`（~64,800行）中。

**理论方法**：采用高阶面元法（Higher-Order Panel Method），在物体表面分布源汇（source）和偶极子（doublet）奇点，通过满足边界条件建立线性方程组，求解未知奇点强度，进而计算表面压力分布和气动力系数。

```

│   ├── inicor()                              # 内存初始化

│           ├── scntrl()  → contrl()           # 步骤4: 控制点
│           ├── sbcond()  → bconcl()/bcopt()   # 步骤5: 边界条件
```

## 详细求解步骤

### 步骤1: 读取输入 — `inputa()` / `sinput()`

**输入文件**：程序启动时提示用户输入文件名，从 unit=5 读取格式化文本。

**输入内容**：

| 类别 | 变量 | 说明 |
|------|------|------|
| Case 标题 | `title1`, `title2` | 双行标题，每行80字符 |
| 来流参数 | `amach` | 自由来流马赫数 |
| | `alpha(1:4)` | 迎角（度），最多4个case |
| | `beta(1:4)` | 侧滑角（度） |
| | `fsvm(1:4)` | 自由来流速度大小 |
| 压缩性方向 | `alpc`, `betc` | 压缩性轴的角度定义 |
| 对称性 | `nsymm` | 对称面数量（0/1/2） |
| 参考量 | `sref`, `bref`, `cref`, `dref` | 参考面积/长度 |
| | `xref`, `yref`, `zref` | 力矩参考中心 |
| 网络定义 | `nnett` | 网络总数 |
| | `nm(k), nn(k)` | 第k个网络的展向×弦向网格点数 |
| | `nts(k), ntd(k)` | 源汇类型 / 偶极子类型 |
| | `zm(3, i)` | 网格点坐标 (x, y, z) |
| 边界条件 | `cu1, cl1, du1, dl1` | 上/下表面质量通量/势系数 |
| | `tu1, tl1` | 上/下表面方向向量 |
| | `nropt1` | 右侧边界条件选项 |
| | `bet1` | 边界条件右端项值 |
| 网络连接 | abutment 数据 | 网络间边界面/尾迹的连接关系 |
| 打印控制 | `igeomp, isingp, ibconp` 等 | 各类诊断输出开关 |
| 数据检查 | `ndtchk` | =0 完整求解; =1 仅数据检查; =2 含几何检查 |

**输出**：所有输入数据存储在 `/index/`, `/acase/`, `/comprs/`, `/bcon/` 等公共块中。

### 步骤2: 面元几何计算 — `geomc()` / `sgeomc()`

对每个网络的面板计算并存储（unit=2）：

| 计算量 | 说明 |
|--------|------|
| `cp(3,9)` | 面板9个规范点坐标（4角点+4边中点+1中心） |
| `en(3,5)` | 面板法向量（5种状态：4边+1整体） |
| `aj(5)` | 面积雅可比（全局/局部面积比） |
| `ar(9,5)`, `ari(9)` | 全局 ↔ 局部面板坐标变换矩阵 |
| `aq(9)`, `aqi(9)` | 全局 ↔ 近平面坐标变换矩阵 |
| `c1, c2, c3` | 四边形偏斜度参数 |
| `diam` | 可压缩面板直径 |
| `alam(9,4)` | 面板λ参数（双二次基相关） |

**相关子程序**：
- `genpan()` — 生成网络面板索引
- `gensub()` — 生成子面板
- `msrotm()` — 计算近平面旋转矩阵
- `geodtc()` — 几何数据检查
- `bqbfun()` — 双二次基函数 ϕ(s,t) 及导数

### 步骤3: 奇点分布定义 — `ssing()` → `daspl()` / `ddwspl()`

定义每个面板上的高阶奇点分布（存储在 unit=2）：

| 奇点类型 | 参数 | 说明 |
|----------|------|------|
| 源汇（source） | `asts(27)` | 9个源汇参数 → 相邻奇点参数的线性关系矩阵 |
| 偶极子（doublet） | `astd(189)` | 9个规范面板偶极子值 → 相邻奇点参数的对应关系 |

**分布形式**：面板上源汇和偶极子均为双二次分布（biquadratic），9个基函数节点对应面板的9个规范点：

```
面板规范点布局 (isoparametric):
    4 ─── 7 ─── 3      s,t ∈ [-1, +1]
    │           │
    8     9     6      ϕ(s,t) = bs(s) × bt(t)
    │           │
    1 ─── 5 ─── 2
```

**基函数**：`bqbfun(s, t, phi, phis, phit)` 计算：
- `bs(1:3)` = 1D二次拉格朗日基（s方向）
- `bt(1:3)` = 1D二次拉格朗日基（t方向）
- `phi(1:9)` = `bs × bt`（双二次张量积）

**偶极子类型**（`ntd`）：
- 类型 1, 2, 3, 6, 12, 18, 20：不同的网格边界/连续性约束

---

### 步骤4: 控制点定义 — `scntrl()` → `contrl()`

为每个网络定义控制点位置及属性（存储在 unit=3）：

| 控制点类型 | 位置 | 说明 |
|------------|------|------|
| 常规（面板中心） | `(ifn, jfn)` = 偶数网格索引 | 面元中心，向内偏移 |
| 边缘控制点 | `ifn=1` 或 `jfn=1` | 网格边界处 |
| 角点控制点 | 网格角点 | 特殊处理 |
| 额外控制点 | 用户指定 | `xtra` 点 |

每个控制点存储：
- `zc(3)` — 控制点坐标
- `znc(3)` — 法向量
- `zdc` — 面元位置标记
- `kabmtc` — abutment 标记
- `tauc` — 参数位置
- `ipc` — 关联面板索引

---

### 步骤5: 边界条件分析 — `sbcond()` → `bconcl()` / `bcopt()`

分析并构建每个控制点的边界条件方程（存储在 unit=1 的 block buffer 中）：

**边界条件类型**：

| `nropt` | 类型 | 说明 |
|---------|------|------|
| 0 | 直接指定 | 直接给定奇点强度值 |
| 1 | Dirichlet | 扰动势 ϕ = 给定值 |
| 2 | Neumann | ∂ϕ/∂n = 给定质量通量 |
| 3 | 对称面 | ϕ = 0 |
| 4 | 排气 | 进气道/喷口 |
| 5 | Kutta 条件 | 尾缘等压/等势 |
| 9 | 特殊Neumann | 带源项 |

每个边界条件记录的存储格式：
```
cu·ϕ_up + cl·ϕ_lo + tu·∇ϕ_up + tl·∇ϕ_lo + du·μ_up + dl·μ_lo = bet
```

**Kutta 条件**：在尾缘处强制上/下表面压力相等（或势差为零）。

**边界条件系数**通过 `btrnsf()` 从输入格式转换为内部矩阵格式。

---

### 步骤6: 影响系数计算 — `svinfc()` → `vinfcc()` / `ffpic()`

计算每个单位奇点强度对每个控制点的势和速度影响（即气动影响系数 AIC）：

**理论基础**：
- **亚音速**（`betams > 0`）：使用 Prandtl-Glauert 变换后的不可压格林函数 `1/(4πr)`
- **超音速**（`betams < 0`）：使用超音速格林函数，影响域限于前马赫锥内

**计算内容**：

| 影响类型 | 源汇 → 控制点 | 偶极子 → 控制点 |
|----------|---------------|-----------------|
| 势 ϕ | ✓ | ✓ |
| 速度 ∂ϕ/∂x, ∂ϕ/∂y, ∂ϕ/∂z | ✓ | ✓ |

**相关子程序**：
- `ffpic()` — 面板影响系数详细计算
- `ffpiv()` — 速度影响系数
- `nftpic()` — 近场影响系数（近距面板特殊处理）
- `nftpiv()` — 近场速度影响
- `dinflu()` — 面板影响域判断（超音速）
- `duzint()` — 双二次面板势/速度积分
- `evalhp()` — 自适应积分精度评估
- `evldmz()` — 超音速偶极子马赫锥判断

**远场/近场分离**：对近距面板使用精确积分，远距面板使用近似公式以加速。

---

### 步骤7: 组装线性系统 — `saical()` → `aical()` / `blkaic()`

将影响系数和边界条件组装为线性方程组 **[A]{x} = {b}**：

**矩阵结构**：
- **[A]** = 左端影响系数矩阵，大小为 `nsngu × nsngu`
  - `A(i,j)` = 第j个未知奇点对第i个方程的贡献
- **{b}** = 右端向量，大小为 `nsngu × nacase`
  - 每列对应一个来流case

**组装过程**：
```
对于每个控制点 jc:
  1. 提取边界条件系数 (cu, cl, tu, tl, du, dl)
  2. 结合影响系数 dvdfs 构建行向量
  3. 将已知奇点贡献移到右端: {b} -= [A_known]×{x_known}
  4. 将未知奇点贡献留在左端矩阵
  5. 处理二阶条件 (cp2 matching) 和 abutment 约束
```

**分块策略**（out-of-core）：
- `nppblk`（默认249）：块大小
- `nqqblk`：子块大小
- AIC矩阵按块写入 unit=27 和 unit=19, unit=20

**相关子程序**：
- `aical()` — 逐行构建矩阵
- `blkaic()` — 分块矩阵构建
- `aicerr()` — 矩阵行一致性检查
- `aicsup()` — 矩阵行补充
- `ibtrns()` / `ictrns()` — 索引变换

---

### 步骤8: 求解线性系统 — `sinver()` → `tinver()` / `bkfact()`

求解 **[A]{x} = {b}** 得到未知奇点参数（偶极子强度 `μ`）。

**求解器**：分块LU分解（out-of-core blocked LU factorization）

**主要子程序链**：
```
sinver()
  └── tinver()          # 总控
      ├── bkfact()      # LU 分解
      │   ├── bkfclu()  # 分块LU (in-core)
      │   ├── blkfac()  # 块矩阵分解
      │   ├── blksit()  # 块矩阵求逆
      │   └── blkstn()  # 块矩阵求解
      └── bkslvt()      # 前向/后向回代
          └── bksolv()
              ├── blkrhs()  # 构建右侧向量
              ├── blkslv()  # 分块前向消元
              └── blksvn()  # 分块后向回代
```

**输入**：
- `naic` (unit=27)：AIC矩阵
- `nrhs` (unit=19)：右端向量
- `nsngu`：未知数数量
- `nacase`：右端case数

**输出**：
- `sols(nsngu, 4)`：解向量 — 每个未知奇点的偶极子强度（每列对应一个来流case）

**支持重启动**：如果 `nckaic=1`，可以跳过AIC计算，直接使用已保存的矩阵求解（`ifact` 标志控制）。

**低频理论扩展**（`lfqind > 0`）：
- `mlofrq=1`：ϕ(0) 基本解
- `mlofrq=2`：d/dt ϕ(0) 解
- `mlofrq=3`：ϕ(1,h) 解

---

### 步骤9: 后处理求解 — `pppdq()` → `dpdqfv()`

从奇点解计算速度场和表面量：

```
pppdq()
  └── dpdqfv()       # 从偶极子/源汇强度计算扰动速度
      ├── ffdqg()    # 细网格扰动速度
      ├── ffdqgv()   # 速度向量组装
      └── dsncdv()   # Cp 计算
```

**细网格速度计算**（`ffdqg`）：每个面板上生成 `(2m-1)×(2n-1)` 的细网格点，在各细网格点上计算扰动速度。

**压力系数**：
```
Cp = -2·ϕ_x / V∞   (线性化，亚音速)
```

通过 `cpcal()` / `cpcalx()` 使用伯努利方程更精确计算。

---

### 步骤10: 力/力矩计算与输出 — `sutput()` → `fmcal()` / `fmkal()` / `indrag()`

**Cp分布**：
- 在每个面板中心计算上/下表面压力系数
- 输出到 `panair.out`

**力/力矩系数** — `fmcal()`：

采用加权最小二乘法对每个面板拟合线性Cp分布，然后积分得到面板力/力矩：

```
F = ∫(Cp·n)·dS    →  CL, CD, CS
M = ∫(r × Cp·n)·dS  →  CMx, CMy, CMz
```

累加层次：面板 → 网络列 → 网络 → 全机构型

**相关子程序**：
- `fmkal()` / `fmcale()` — 不同输出级别的力/力矩计算
- `lsqsf()` — 最小二乘拟合
- `integr()` — 面板积分
- `blccal()` — 网络列力/力矩汇总
- `fmcal()` — 总力/力矩汇总

**诱导阻力** — `indrag()`：
- 使用 Trefftz 平面法（远尾迹截面上积分）
- 输入尾迹网络数据（y, z 坐标及其导数的Trefftz平面值）
- 计算 `cdi`（诱导阻力系数）、`eff`（效率因子）、`cl`

**输出文件**：
- `panair.out` (unit=6)：主输出文件，包含：
  - 输入数据摘要（`insumm()`）
  - 几何和边界条件摘要
  - 各网络面板 Cp 分布
  - 总力/力矩系数表
  - 诱导阻力结果
- `panair.err` (unit=7)：错误和警告信息

---

### 步骤11: 离体点计算（可选）— `soffbd()`

当 `nflowv ≠ 0` 时激活。计算用户指定空间点的流动量：
- 扰动速度 `vp`
- 扰动势 `ϕp`
- 压力系数 `Cp`

**输入**：`ntv` (unit=4) 上的离体点坐标和求解结果。

---

### 步骤12: 流线追踪（可选）— `stmlne()`

当 `nstmln ≠ 0` 时激活。从用户指定起点追踪空间流线：

**参数**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `numpts` | 0 | 流线数量（最大500） |
| `hmin` | 1e-7 | 最小步长 |
| `hmax` | 10000 | 最大步长 |
| `maxstm` | 1000 | 每条流线最大积分点数 |
| `mxordr` | 6 | 最高积分阶数 |
| `abserr` | 1e-6 | 积分误差容限 |
| `tpsl` | 0.0 | =0 质量通量流线; ≠0 速度流线 |

**方法**：使用自适应变阶/变步长ODE积分器（`fsolve()` → `fhybrj()`）。

**输出**：流线坐标写入 unit=33。

---

### 步骤13: 最终输出 — `cstsum()` / `cstprt()`

`cstsum()` 打印整个求解过程的总耗时摘要（CPU时间），各步骤时间通过 `cost()` 记录在 `/jobsum/` 公共块中。`cstprt()` 在各关键步骤后打印阶段性状态。

## 关键技术特点

### 1. 高阶面元
- 面板几何和奇点分布均采用 **双二次等参（biquadratic isoparametric）** 表示
- 每个面板9个规范点（4角 + 4边中点 + 1中心）
- 9个双二次基函数 `ϕ(s,t) = L_i(s)·L_j(t)`, `i,j ∈ {1,2,3}`

### 2. 亚/超音速统一框架
- 通过 Prandtl-Glauert 变换处理压缩性
- `betams = 1 - M²`：正为亚音速（椭圆型），负为超音速（双曲型）
- 格林函数自动切换：`akap = π(3+sbetam)`（亚: 4π, 超: 2π）

### 3. 外存分块求解器
- AIC矩阵可极大（最大 24000×24000）
- 使用分块LU分解 + 外存存储
- 通过 `/blkprm/` 控制块大小（默认249行/块）
- 支持重启动（保存/读取已分解矩阵）

### 4. 网络连接（Abutment）
- 支持多网络拼接成复杂构型
- 自动处理网络间网格点的等效匹配
- Kutta 条件自动施加于尾缘
- 尾迹网络自动生成

### 5. 对称面处理
- 支持 0/1/2 个对称面
- 通过镜像法自动处理（`ictsym = 1/3/15`）
