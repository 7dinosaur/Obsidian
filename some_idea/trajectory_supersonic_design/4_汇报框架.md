# 汇报框架：考虑航迹规划的超声速民机总体设计

> 用途：组会 / 导师汇报
> 时长：15—20 分钟
> 结构：痛点 → 替代路径 → 框架 → 预期

---

## 一、一句话概括

**声爆限制不一定要用低声爆气动设计硬扛——把声爆约束从总体设计阶段前置到航迹规划阶段，用"绕飞"换"气动设计自由度"，总体设计从多目标权衡退化为单目标优化。**

---

## 二、问题的重新审视

### 2.1 现行路径的代价

超声速民机 → 声爆必须达标 → 低声爆气动布局设计：

| 代价 | 量级 |
|------|------|
| 巡航 L/D 损失 | 文献报告 5-15% |
| 结构重量增加 | 文献报告 3-8% |
| 大载客量兼容性 | 客舱体积 ↑ → 等效截面积 ↑ → 声爆 ↑ → 矛盾难以调和 |

### 2.2 一个被忽视的事实

**声爆只影响地面。** 不在人口密集区上空超声速飞行，就没有声爆约束。

→ 为什么不在航迹上绕开声爆禁飞区，然后把节省下来的设计自由度全部用于提升气动效率？

### 2.3 两种策略的对比

```
路径A（现行）：低声爆气动设计
  L/D ↓ 5-15%，重量 ↑ 3-8% → 油耗 ↑

路径B（本文）：航迹规避 + 纯气动优化
  绕飞航程 ↑ Z% → 油耗 ↑
  L/D 不损失，重量不增加
```

**哪个代价更小？——这是本文要回答的核心问题。**

## 三、核心框架

### 3.1 总体思路

```
声爆约束 ──→ 航迹规划（前置处理）──→ 产出声爆规避航迹
                                            ↓
                  飞机总体设计 ←── 飞行剖面优化 ←──┘
                  （无声爆约束）    （给定航迹下）
                       ↓
                  目标：纯燃油最小化
```

### 3.2 多学科设计框架（XDSM 图）

```
                    ┌─────────────┐
                    │  航迹规划    │ ← 机场对 + 声爆禁飞区
                    │  声爆约束    │
                    └──────┬──────┘
                           │ 航迹几何
                    ┌──────▼──────┐
                    │ 飞行剖面优化 │ ← 飞机参数初值
                    │  燃油最小化   │
                    └──────┬──────┘
                           │ 最优剖面 + 油耗
              ┌────────────┼────────────┐
              │            │            │
       ┌──────▼──┐  ┌─────▼───┐  ┌────▼───┐
       │ 气动分析 │  │ 重量估算 │  │ 性能计算│
       │ 代理模型 │  │ 经验公式 │  │ Breguet │
       └──────┬──┘  └─────┬───┘  └────┬───┘
              │            │            │
              └────────────┼────────────┘
                           │
                    ┌──────▼──────┐
                    │  飞机参数优化│
                    │  油耗最小化  │
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │  最优方案    │
                    └─────────────┘

虚线可选回路（耦合强度分析决定是否激活）：
  飞机参数 ←→ 飞行剖面
  飞机参数 ←→ 航迹
```

### 3.3 方法论亮点：耦合强度分析

不回避"序贯优化是否足够"的问题，而是主动量化：

- 扰动飞机参数 → 观察最优剖面是否偏移
- 扰动飞行剖面 → 观察燃油消耗敏感性
- 定义交叉敏感性系数
- 耦合弱 → 序贯有依据；耦合强 → 序贯迭代有贡献

## 四、关键技术模块

| 模块 | 方法 | 关键输出 |
|------|------|---------|
| 航迹规划 | A* 图搜索 + 声爆禁飞区约束 | 声爆规避航迹 + 距离增量 |
| 声爆预测 | Carlson / 波形参数法简化模型 | 声爆走廊边界 |
| 飞行剖面优化 | 直接配点法 / 最优控制 | 最优高度-Ma 时间历程 |
| 气动代理模型 | Kriging / RBF | 各飞行状态 L/D |
| 重量估算 | GD 方法 / 半经验公式 | 起飞重量 / 空重 |
| 飞机参数优化 | 进化算法 / 梯度优化 | 最优总体参数 |

## 五、代价权衡分析（核心差异化贡献）

### 5.1 思路

不比较具体飞机型号（数据不公开），比较两种策略的物理代价：

| | 低声爆路径 | 绕飞路径 |
|------|-----------|---------|
| L/D | 损失 5-15% | 不损失 |
| 重量 | 增加 3-8% | 不增加 |
| 航程 | 大圆弧 | 绕飞 +Z% |

### 5.2 Breguet 统一比较框架

三种代价统一折算为当量油耗增量 → 同口径对比

### 5.3 参数化敏感性分析

- 横轴：低声爆技术成熟度（L/D 损失、重量代价）
- 纵轴：当量油耗
- 绕飞策略：水平参考线
- 曲线交叉点 → 策略切换条件

**不回答"哪个更好"，回答"在什么条件下哪个更好"——更有学术价值。**

## 六、案例研究

### 6.1 航线
跨太平洋（上海→洛杉矶，~10,400 km 大圆弧），大部分航程在海洋上空。

### 6.2 市场论证（双路径）
- 路径一：全球跨洋航线网络 → 可支撑机队规模
- 路径二：纯陆地航线截止马赫数飞行 → 即使无声爆限制是否本无竞争力？

### 6.3 预期结果
- 完整的超声速民机总体方案（三视图 + 参数表）
- 声爆规避航迹 + 最优飞行剖面
- 与亚声速宽体机的时间/经济性对比

## 九、风险与应对

| 风险 | 应对 |
|------|------|
| 耦合强度分析发现耦合不可忽略 | 不回避，升级为序贯迭代框架；这是一个同样有价值的发现 |
| 声爆简化预测精度不够 | 保守禁飞区边界（加安全裕度）；概念设计阶段精度可接受 |
| 代理模型精度不达标 | 增加样本点 / 改用更灵活模型 / 多保真度方法 |
| 文献中低声爆代价数据不够 | 扩大搜索范围到 NASA TP、AIAA 综述；用保守范围代替精确值 |
| cVAE 那边的数据不支持 | 这两个工作并行推进，互不阻塞 |
