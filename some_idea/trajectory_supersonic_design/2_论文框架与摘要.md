# 论文框架与摘要

> 目标期刊：中文航空类期刊（《航空学报》或同级）
> 暂定标题：考虑航迹规划的超声速民机总体设计

---

## 摘要（拟）

声爆限制是制约超声速民机商业化的核心障碍。传统应对策略聚焦于低声爆气动布局设计，但低声爆构型通常以升阻比损失和结构增重为代价，且大载客量低声爆布局的可行性尚未得到验证。本文提出一种替代思路：将声爆约束前置到航迹规划阶段处理，在航迹规避声爆敏感区的前提下，总体设计阶段仅需面向燃油经济性进行单目标优化。为此，建立了"航迹规划—飞行剖面优化—飞机总体参数优化"的序贯设计框架，并通过交叉敏感性分析量化耦合强度以验证序贯近似的合理性。以跨太平洋航线为应用场景，在规避声爆禁飞区的航线约束下，联合优化飞行高度-马赫数剖面与飞机总体参数。进一步建立了绕飞策略与低声爆设计策略的代价权衡分析方法——基于Breguet航程公式将L/D损失、结构增重与绕飞距离增量统一折算为当量油耗，给出两种策略的竞争力区间。结果表明：（待补）。本文建立的框架为超声速民机的总体设计提供了一种新的方法论选择——以航迹自由度换取气动设计自由度。

## 一、引言

### 1.1 研究背景
- 超声速民机复兴趋势（Boom Overture、NASA X-59等）
- FAA/ICAO 陆上超声速飞行禁令——声爆是型号研制的核心瓶颈
- 当前主流路径：低声爆气动布局设计

### 1.2 低声爆路径的代价
- 低声爆修形导致 L/D 下降（文献量级：5-15%）
- 细长机身/特殊机头形状带来的结构重量代价（文献量级：3-8%）
- 大载客量与低声爆的兼容性困境：客舱体积 ↑ → 等效截面积 ↑ → 声爆 ↑
- 低声爆布局的详细气动/重量数据不公开，无法在型号设计前准确评估代价

### 1.3 另一条路径：航迹规避
- 声爆只影响地面，通过航迹规划绕开人口密集区
- Boom Overture 的商业模型即建立在此假设上（只飞跨洋航线）
- 航迹规避 + 纯气动优化 vs 低声爆设计 —— 两种策略的代价从未被系统对比

### 1.4 既有工作
- XXX et al. 的布局-经济性分析框架（肯定贡献，不赘述差异）
- 总体设计中考虑航迹/任务优化的已有研究（亚声速方面）
- 研究空白：尚无将航迹规划前置到超声速民机概念设计阶段、并与总体参数协同优化的系统框架

### 1.5 本文工作
- **核心思路**：将声爆约束前置到航迹规划阶段处理 → 总体设计优化的目标从"低声爆+低油耗多目标权衡"退化为"低油耗单目标"
- **框架建立**：航迹规划 → 飞行剖面优化 → 飞机总体参数优化的序贯设计框架，含耦合强度分析模块
- **代价权衡**：建立绕飞策略与低声爆策略的统一对比方法论
- **案例验证**：以跨太平洋航线为场景完成设计循环，给出最优方案

## 二、多学科设计框架

### 2.1 问题定义
- **设计变量**：航迹几何参数、飞行剖面参数（高度/马赫数时间历程）、飞机总体参数（翼面积、展弦比、后掠角、推重比、翼载荷等）
- **约束**：声爆禁飞区（航迹端）、飞行包线/推力/动压限制（剖面端）、几何/重量/起降性能（飞机端）
- **目标**：最小化任务燃油消耗（或燃油消耗率 per seat-km）

### 2.2 学科分解与数据流（XDSM 图）

```
学科模块：
  A. 航迹规划：给定起降机场对 + 声爆禁飞区 → 输出最优 3D 航迹
  B. 飞行剖面优化：给定航迹 + 飞机参数初值 → 输出最优高度-马赫数剖面 + 燃油
  C. 气动分析：给定飞机参数 + 飞行剖面点 → 输出各状态 L/D
  D. 重量估算：给定飞机参数 → 输出起飞重量/空重
  E. 性能计算：集成气动 + 重量 + 剖面 → 输出任务油耗（耦合 Breguet + 爬升积分）

数据流：
  A → B（航迹坐标、各段距离）
  B → E（剖面参数、各段飞行状态）
  C → E（各状态 L/D）
  D → E（各阶段重量）
  E → B（燃油消耗量，用于迭代）
  E → [收敛判断] → 可能需要回传 A 重新规划（耦合强度分析决定是否激活）
```

- 序贯主路径：A → B → C/D → E
- 虚线可选迭代回路：E → A / E → B（待耦合强度分析确认是否需要）
- 代理模型位置：气动分析（C）使用 Kriging/RBF 代理模型以减少面元法/CFD 调用

### 2.3 耦合强度分析（方法论创新点）

**目标**：判断序贯优化是否足够，还是需要协同优化迭代。

**方法**：
1. 在最优飞机参数附近扰动关键变量（翼载荷 ±10%、推重比 ±10%）
2. 回代到航迹优化/剖面优化模块，观察最优航迹和剖面是否显著偏移
3. 在最优剖面附近扰动飞行剖面参数（巡航 Ma ±0.05，巡航高度 ±1000m），观察燃油消耗敏感性
4. 定义交叉敏感性系数：\( S_{ij} = \frac{\partial \text{Fuel}}{\partial x_i \partial p_j} \)

**判定准则**：
- 如果交叉敏感性 < 阈值：序贯近似合理，无需迭代 → 论文有方法论依据
- 如果交叉敏感性 ≥ 阈值：耦合不可忽略 → 引入序贯迭代外环 → 论文有方法论贡献

## 三、航迹规划模型

### 3.1 声爆预测与禁飞区划定
- 声爆强度简化预测（Carlson/波形参数法 或 近场-远场传播简化模型）
- 禁飞区：人口密集区 → 声爆禁止；海洋/极地/特定走廊 → 允许
- 声爆走廊宽度与航路偏移容限

### 3.2 最优航迹求解
- 输入：起降机场对、禁飞区多边形、风场（可选）
- 目标：最小化航程（或最小化总飞行时间）
- 约束：不穿越禁飞区
- 方法选择：图搜索（A*）处理静态禁飞区 / 最优控制处理动态约束
- 对特定航线给出确定的最优航迹

### 3.3 典型航线结果
- 跨太平洋（上海→洛杉矶）：大圆弧 vs 声爆规避航迹的距离对比
- 其他候选航线（视需要）

## 六、代价权衡分析：绕飞 vs 低声爆

### 6.1 分析框架
- 基本问题：绕飞增加的航程 vs 低声爆设计增加的气动和重量代价
- 统一比较基准：Breguet 航程公式下的当量燃油消耗率

### 6.2 低声爆设计的已知代价（文献综述）
- L/D 损失量级：文献报告 5-15%
- 结构重量代价量级：文献报告 3-8%
- 上述代价折算为当量油耗增量的公式

### 6.3 绕飞策略的航程代价
- 绕飞航程 vs 大圆弧最短航程（精确可算）
- 以跨太平洋航线为示例量化

### 6.4 参数化敏感性分析
- 横轴：低声爆技术成熟度（L/D 损失从 0 到 15%，重量代价从 0 到 8%）
- 纵轴：当量油耗
- 绕飞策略作为一个水平参考线（航程固定增加 Z%，无气动/重量代价）
- 两条曲线的交叉点 → 低声爆技术需要达到什么水平才能优于绕飞策略

### 6.5 讨论
- 当前低声爆技术水平下，绕飞策略是否有竞争力
- 低声爆技术发展路径的可预见里程碑（X-59 → 适航认证 → 型号应用）
- 策略的动态切换建议：短期绕飞 + 长期低声爆融合
- 对本文最优方案的验证含义

## 八、结论

### 8.1 主要工作与发现
- 建立了考虑航迹规划的超声速民机总体设计序贯框架
- 耦合强度分析验证了（或挑战了）序贯近似的合理性
- 绕飞策略与低声爆策略的当量油耗对比分析
- 案例研究给出了完整的飞机方案

### 8.2 核心贡献
- **框架贡献**：建立了"航迹规划前置解耦声爆约束"的总体设计方法论，以航迹自由度换取气动设计自由度
- **方法贡献**：提出了耦合强度分析的量化方法，用于验证序贯近似的合理性
- **工程贡献**：建立了绕飞 vs 低声爆两种策略的统一代价权衡框架

### 8.3 未来工作
- 低声爆技术成熟后的策略融合（部分低声爆 + 部分绕飞的混合策略）
- 多航线联合优化（一架飞机对多条航线的综合最优设计）
- 将更多学科（排放、噪声、成本）纳入框架
