# 工作计划：考虑航迹规划的超声速民机总体设计

> 总体周期：10~14 周
> 最终交付：中文期刊论文全文 + 完整优化框架代码

---

## 阶段零：框架骨架搭建（第 1—2 周）

### 目标
确认多学科模块均可独立运行，XDSM 框架的数据流和接口定义清晰，各模块间的输入输出格式锁定。

### 具体任务
- [ ] 完成 XDSM 图的正式绘制（含序贯主路径 + 可选迭代回路虚线）
- [ ] 定义各学科模块的接口规范（输入/输出变量名、维度、单位）
- [ ] 航迹规划模块：实现禁飞区约束 + 大圆弧最短路径 + 声爆规避航迹求解（初版可用简化几何方法 / A* 图搜索）
- [ ] 飞行剖面参数化模块：实现高度-马赫数剖面的分段参数化 + Breguet 燃油积分
- [ ] 气动分析模块：面元法/CFD 批处理脚本就绪（或代理模型基础数据准备）
- [ ] 重量估算模块：经验公式实现（参考 Roskam/Raymer/GD 方法）
- [ ] 端到端管线：固定一组飞机参数 → 航迹 → 剖面 → 燃油消耗，确认无 bug

### 验收项
- [ ] XDSM 图定稿
- [ ] 各模块接口文档（代码内注释 + 简要说明）
- [ ] 端到端 1 组参数跑通，输出有物理意义的结果
- [ ] 各模块独立测试通过

---

## 阶段一：航迹规划与飞行剖面优化（第 2—4 周）

### 目标
完成航迹规划和飞行剖面两个前置模块的优化，产出声爆规避航迹和在给定飞机参数下的最优飞行剖面。

### 具体任务

**1.1 声爆约束建模（第 2 周）**
- [ ] 选定声爆强度简化预估方法（Carlson 方法/波形参数法/其他）
- [ ] 建立禁飞区数据集：全球人口密集区 → 声爆禁飞多边形
- [ ] 定义声爆走廊（允许超声速飞行的海洋/极地区域）
- [ ] 参数化起降机场对，建立航迹规划问题标准格式

**1.2 航迹优化求解（第 2—3 周）**
- [ ] 实现大圆弧最短路径（对比基线）
- [ ] 实现声爆规避航迹求解（A* 或最优控制方法）
- [ ] 计算绕飞距离增量 Δ%（相对大圆弧）
- [ ] 给出 3—5 条典型跨洋航线的航迹结果

**1.3 飞行剖面优化（第 3—4 周）**
- [ ] 剖面参数化（爬升/加速/巡航/减速/下降各段的参数）
- [ ] 建立飞行包线约束（动压、Ma-高度边界、推力限制）
- [ ] 实现剖面优化求解器（直接配点法/间接法）
- [ ] 给定固定飞机参数（合理初值），优化获得最优剖面
- [ ] 记录各飞行段的燃油消耗分解

### 验收项
- [ ] 跨太平洋航线声爆规避航迹结果（含距离增量）
- [ ] 最优飞行剖面（高度-马赫数时间历程）
- [ ] 燃油消耗分解表
- [ ] 与亚声速大圆弧基线的初步对比

## 阶段二：耦合强度分析（第 4—5 周）

### 目标
量化航迹-剖面-飞机参数之间的交叉敏感性，判断序贯优化是否足够，或是否需要激活迭代回路。这是论文的方法论核心贡献之一。

### 具体任务

**2.1 剖面 ← 飞机参数的敏感性（第 4 周）**
- [ ] 在最优飞机参数附近做参数扰动：翼载荷 ±10%、推重比 ±10%、展弦比 ±15%
- [ ] 每组扰动参数下重新优化飞行剖面
- [ ] 记录最优剖面的偏移量：巡航高度 Δh、巡航 Ma 的 ΔM
- [ ] 记录燃油消耗的变化量 ΔFuel

**2.2 航迹 ← 飞机参数的敏感性（第 4 周）**
- [ ] 在最优飞机参数附近扰动关键变量
- [ ] 回代航迹优化模块，观察最优航迹是否显著变化
- [ ] 分析声爆约束对航迹的"锁定"效应：是否声爆禁飞区位置主导了航迹选择，飞机参数差异无法改变航迹

**2.3 综合分析（第 5 周）**
- [ ] 计算交叉敏感性系数矩阵
- [ ] 判定耦合强度等级（弱/中/强）
- [ ] 决策：序贯框架可行 / 需要迭代外环
- [ ] 撰写耦合强度分析小节（论文 2.3 节素材）

### 验收项
- [ ] 交叉敏感性系数计算结果
- [ ] 耦合强度判定结论
- [ ] 若需迭代：迭代收敛性验证 + 序贯解与迭代解的差距量化

---

## 阶段三：飞机总体参数优化（第 5—7 周）

### 目标
在固定航迹和飞行剖面下，完成飞机总体参数的优化设计，获得最优飞机方案。

### 具体任务

**3.1 代理模型构建（第 5—6 周）**
- [ ] 确定设计空间范围（各总体参数的上下界）
- [ ] 试验设计（DoE）：拉丁超立方采样，50-100 个样本点
- [ ] 每个样本点的高保真气动计算（面元法 / SU2 Euler）
- [ ] 代理模型构建（Kriging / RBF / 神经网络）
- [ ] 代理模型精度验证（留一交叉验证 / 独立测试集）

**3.2 重量模型（第 5 周）**
- [ ] 选型重量估算方法（GD 方法 / 统计回归 / 半经验公式）
- [ ] 各部件重量：机翼、机身、尾翼、起落架、发动机、系统、燃油
- [ ] 重心位置与配平约束

**3.3 优化求解（第 6—7 周）**
- [ ] 建立优化数学模型（设计变量、约束、目标函数）
- [ ] 算法选择与实现（梯度优化器 SNOPT / 进化算法 NSGA-II / 混合策略）
- [ ] 多起点优化避免局部最优
- [ ] 优化收敛性监控与结果可信度评估

**3.4 最优方案分析（第 7 周）**
- [ ] 最优飞机参数表
- [ ] 三视图 / 主要几何尺寸
- [ ] 重量分解
- [ ] 各飞行状态的 L/D 分布

### 验收项
- [ ] 代理模型精度满足要求（R² > 0.95 或 RMSE < 5%）
- [ ] 优化收敛，最优方案物理合理
- [ ] 飞机方案参数表完整
- [ ] 与亚声速基准的对比数据

## 阶段四：代价权衡分析（第 7—8 周）

### 目标
建立绕飞策略与低声爆设计策略的定量对比分析框架。这是论文的第二个方法论贡献。

### 具体任务

**4.1 文献数据整理（第 7 周）**
- [ ] 搜集公开文献中低声爆气动设计的 L/D 损失数据（范围，不要求精确点值）
- [ ] 搜集结构增重数据（范围）
- [ ] 整理为可引用的数据表格

**4.2 Breguet 统一比较框架（第 7 周）**
- [ ] 推导 L/D 损失 → 当量油耗增量的转换公式
- [ ] 推导结构增重 → 当量油耗增量的转换公式
- [ ] 推导绕飞航程增量 → 当量油耗增量的转换公式
- [ ] 确认公式中各参数的物理合理范围

**4.3 参数化敏感性分析（第 7—8 周）**
- [ ] 横轴参数扫描：L/D 损失 0-15%，结构增重 0-8%
- [ ] 绕飞策略作为参考线（航程增量固定，无气动/重量代价）
- [ ] 两条曲线的交叉分析 → 竞争力条件的数学表达
- [ ] 给出当前技术水平下的定性判断

**4.4 讨论撰写（第 8 周）**
- [ ] 短期策略建议（低声爆不成熟 → 绕飞优先）
- [ ] 中长期策略建议（低声爆成熟 → 策略融合/切换）
- [ ] 对本文最优方案的验证含义

### 验收项
- [ ] 代价权衡分析图表（参数化敏感性曲线）
- [ ] 竞争条件的数学表达
- [ ] 讨论部分的完整论述

## 阶段五：案例研究与市场论证（第 8—9 周）

### 目标
以跨太平洋航线为完整案例，跑通全链设计循环，输出最优飞机方案。补充市场论证和截止马赫数验证。

### 具体任务

**5.1 跨太平洋案例（第 8 周）**
- [ ] 上海→洛杉矶航线参数（大圆弧距离、禁飞区分布）
- [ ] 全链优化执行：航迹 → 剖面 → 飞机参数
- [ ] 若耦合强度分析判定需要迭代：执行迭代外环至收敛
- [ ] 最终最优方案的完整呈现

**5.2 市场论证（第 8—9 周）**
- [ ] 全球 Top 20 跨洋航线梳理
- [ ] 跨洋航线年客运量估算
- [ ] 超声速票价溢价假设 × 座位数 → 年收入估算
- [ ] 可支撑的超声速民机机队规模

**5.3 截止马赫数验证（第 9 周）**
- [ ] 选一条纯陆地航线（如北京→广州）
- [ ] 全程亚声速巡航（Ma ~0.95）的飞行时间
- [ ] 与同级别亚声速宽体机的时间对比
- [ ] 结论：若节省 < 20-30%，超声速飞机本就不适用于陆地航线 → 声爆限制未损失市场

**5.4 综合对比（第 9 周）**
- [ ] 本文方案 vs 亚声速基准：时间、油耗、经济性
- [ ] 参数敏感性：关键参数 ±10% 对油耗/经济性的影响
- [ ] 方法局限性讨论

### 验收项
- [ ] 案例研究全链结果
- [ ] 市场论证数据
- [ ] 截止马赫数验证结论

## 风险预案

| 风险 | 概率 | 影响 | 预案 |
|------|------|------|------|
| 耦合强度分析显示耦合不可忽略 | 中 | 框架从序贯升级为迭代，增加工作量 ~2 周 | 提前准备迭代框架骨架；将"发现耦合不可忽略"转为方法论贡献 |
| 声爆预测方法精度不够 | 中 | 航迹规划结果不可信 | 使用保守的禁飞区边界（加 10-20% 安全裕度）；参考文献中的简化方法已足够概念设计 |
| 代理模型精度不达标 | 中 | 飞机优化结果不可靠 | 增加 DoE 样本点数；改用更灵活的代理模型；考虑多保真度方法 |
| 文献中低声爆代价数据缺乏 | 中 | 代价权衡分析不扎实 | 扩大搜索范围到 NASA TP、AIAA 综述、PhD 论文；用保守范围代替精确值 |
| 市场数据获取困难 | 低 | 市场论证偏弱 | 用公开的 IATA/OAG 航线数据做粗略估算；重点放在方法框架而非精确市场预测 |
| 整体进度延迟 | 中 | 错过投稿窗口 | 阶段三（飞机优化）和阶段四（代价权衡）可部分并行；代价权衡不依赖飞机优化结果 |

## 并行化机会

- 阶段一（航迹+剖面）和阶段三（飞机优化）的代理模型构建可部分并行
- 阶段四（代价权衡）与阶段三（飞机优化）相对独立，可同步进行
- 阶段五（市场论证）可提前启动，不依赖优化结果
