## 阶段一：数据集构建（第1—3周）

### 目标
构建 1000~2000 个光顺、客舱达标、(condition, geometry) 样本对的数据集。

### 具体任务

**1.1 游走参数调优（第1周）**
- [ ] 测试不同σ（步长）下的接受率，找最优区间（目标接受率 30%~50%）
- [ ] 测试不同扰动维度比例（10%, 30%, 50%）下的光顺性通过率
- [ ] 确定快速筛选的阈值：(a) 相邻站位前缘后缘最大差值；(b) 翼型最小厚度
- [ ] 确定多链游走的链数（建议 4~8 链从不同基准出发）

**1.2 批量生成（第1—2周）**
- [ ] 启动随机游走采样，目标 2000~3000 个候选
- [ ] 监控：光顺性通过率、客舱体积通过率、游走链的覆盖范围
- [ ] 对通过快速筛选的候选跑面元法，计算面积分布
- [ ] 对面积分布做轻度平滑（局部多项式拟合/低通滤波），减少数值噪声

**1.3 数据清洗（第2—3周）**
- [ ] 剔除面积分布异常的样本（如面积出现负值——标记为面元法数值问题）
- [ ] 检查面积分布与geometry之间的物理一致性（如机翼区域面积 ≈ 0 但参数里有翼 → 异常）
- [ ] 归一化：condition和geometry分别fit scaler，存储scaler参数以便推理时逆变换

**1.4 数据划分（第3周）**
- [ ] 按面积分布的相似度做聚类，按聚类 split 训练集/验证集/测试集（比例 70/15/15）
- [ ] 确保测试集包含基准构型和JSGD目标面积附近的样本
- [ ] 可视化：训练集和测试集面积分布的覆盖范围，确认无严重外推

### 验收项
- [ ] 有效样本数 ≥ 1000
- [ ] 客舱体积达标率 100%
- [ ] 几何光顺性（展向一阶差分）检查通过率 ≥ 95%
- [ ] 训练集/验证集/测试集的面积分布覆盖范围可视化确认合理
- [ ] 归一化scaler已存储

## 阶段二：cVAE模型搭建与训练（第3—5周）

### 目标
训练可用的cVAE模型，实现给定面积分布 → 生成多个候选geometry。

### 具体任务

**2.1 模型实现（第3周）**
- [ ] 实现CVAE类（PyTorch）：Encoder + Decoder + reparameterize + forward
- [ ] 实现β-annealing调度器
- [ ] 实现数据加载器（dataloader），确认batch处理正确
- [ ] 添加condition skip connection到decoder中间层
- [ ] 单元测试：固定输入，确认前向/反向传播无报错，输出维度正确

**2.2 超参搜索（第3—4周）**
- [ ] 固定训练集，网格搜索以下组合：
  - Z = [8, 16, 32, 64]
  - hidden_dim = [256, 512]
  - β_final = [0.1, 0.5, 1.0]
- [ ] 每个组合训练完成后记录：
  - 验证集 reconstruction MSE
  - KL loss 是否塌缩
  - 采样100个候选的面积RMSE均值
- [ ] 选最优超参组合

**2.3 模型训练与诊断（第4周）**
- [ ] 用最优超参正式训练，保存最佳模型checkpoint
- [ ] 记录训练曲线：recon_loss、kl_loss、total_loss随epoch变化
- [ ] 训练完成后诊断：
  - 随机采样的z是否确实服从N(0,I)分布（统计检验）
  - 不同z生成的geometry是否有差异（成对欧氏距离）
  - 面积匹配精度是否显著优于随机猜测基线

**2.4 推理管线（第4—5周）**
- [ ] 实现 `sample_candidates(area_target, n_samples, decoder)` 函数
- [ ] 实现后处理：geometry逆归一化 → CST参数 → 3D外形重建

### 验收项
- [ ] 验证集 reconstruction MSE < 基准值（纯AE的MSE做对比基线）
- [ ] KL loss 未塌缩（值 > 0.01）
- [ ] 50次不同z采样产生的geometry成对欧氏距离方差 > 阈值（证明多样性）
- [ ] 面积匹配RMSE显著低于基准构型的面积偏差
- [ ] 模型checkpoint已保存，推理管线可独立运行

## 阶段三：验证实验（第5—7周）

### 目标
完成五层验证递进，获取所有对比数据和图表。

### 具体任务

**3.1 验证1：重建精度（第5周）**
- [ ] 测试集100个样本，计算reconstruction MSE
- [ ] 对比纯自编码器（Z → 更小或无Z）的重建MSE
- [ ] 可视化：最好/最差重建的翼型对比

**3.2 验证2：面积匹配能力（第5周）**
- [ ] 用JSGD目标面积分布作为condition
- [ ] 采样200个候选，计算每个的真实面积 vs 目标RMSE
- [ ] 记录RMSE分布（直方图 + 均值/标准差）
- [ ] 对比：传统JSGD优化达到同等RMSE的迭代次数

**3.3 验证3：多样性（第5—6周）**
- [ ] 同一目标面积，采样50个z → 50个geometry
- [ ] 计算成对欧氏距离的统计量
- [ ] 可视化：展向参数（前缘x、前缘z、后缘x）沿展向的50条曲线束
- [ ] 可视化：3-5个代表性候选的3D外形侧视图叠加

**3.4 验证4：物理合理性（第6周）**
- [ ] cVAE生成100个候选 vs 传统JSGD全机优化100个中间解
- [ ] 定量对比：展向一阶差分均值、翼型负厚度出现率
- [ ] 定性对比：最差cVAE候选 vs 最差JSGD解的3D外形图
- [ ] 统计数据应显著支持cVAE

**3.5 验证5：端到端全机 vs 分段（第6—7周）**
- [ ] 跑传统JSGD分段优化：机翼（固定机身）→ 机身（固定机翼）→ 头部
- [ ] 记录分段最优解的PLdB、L/D、几何光顺性
- [ ] 从cVAE候选池（200个，从验证2）中按面积RMSE + PLdB + L/D选最优
- [ ] 端到端对比表：PLdB、L/D、面积RMSE、展向差分均值、人工干预次数
- [ ] 计算cVAE解相对于分段解的改进幅度（ΔPLdB至少 > 3dB且分段解不存在光顺的合理外形才够有说服力）

### 验收项
- [ ] 五层验证的全套数据（数值 + 图表源数据）准备齐全
- [ ] 验证5的端到端对比：cVAE全机解在PLdB和几何光顺性上均优于传统分段解
- [ ] 若验证5结果不理想（cVAE未显著优于分段），需准备分析原因

## 风险预案

| 风险 | 概率 | 预案 |
|------|------|------|
| 随机游走接受率过低 | 中 | 调大σ或从更多基准构型出发；加宽快速筛选阈值 |
| cVAE的KL塌缩 | 高 | 延长β=0预热、减小β目标值、减小Z维度 |
| 面积匹配精度差 | 中 | 增大网络容量、增加数据量、在loss中增加面积匹配项 |
| 验证5不显著（最优解不比分段好） | 中 | 分析原因（数据不够多样？隐变量信息不足？）；考虑将重点从"超越"转为"替代"（效率优势） |
| 传统分段优化无法复现基准结果 | 低 | 用已保存的4月JSGD优化结果作为分段对比基线 |
