# 论文框架与摘要

> 目标期刊：ICAS (International Council of the Aeronautical Sciences)
> 暂定标题：Data-Driven Full-Configuration Low-Boom Inverse Design for Large Supersonic Blended-Wing-Body Transport via Conditional Variational Autoencoder

---

## 摘要（拟）

声爆不达标与载客量偏小是制约新一代超声速民机商业化的两大核心障碍。大容量翼身融合布局（BWB）有望同时提升载客能力与气动效率，但在低声爆设计中面临根本困难：客舱体积的硬约束导致等效截面积偏高，传统JSGD全机优化因设计变量过多而频繁产生奇异外形，而分段优化虽能抑制奇异解，却以丢失翼身耦合和依赖工程经验为代价。针对这一两难，本文提出一种基于条件变分自编码器（cVAE）的数据驱动全机低声爆反设计方法。该方法以CST全机参数化为基础，构建等效截面积分布与三维几何参数之间的双向映射：以面积分布为条件、以隐变量承载反问题中固有的多解性，通过单次条件采样即可批量生成物理可实现的候选外形。在此基础上，耦合面元法近场声爆预测与SU2 Euler气动分析，建立面积匹配精度—声爆强度—升阻比的多目标选型准则，实现免分段、免手工约束的全机低声爆设计闭环。针对160座级BWB构型开展验证：在相同客舱体积约束下，传统JSGD分段优化最优结果为XX PLdB且翼身过渡区存在几何不规则，而本文方法所筛选的最优构型地面声爆强度降至XX PLdB（较基准降低XX dB），升阻比达到XX，且全机几何外形的展向一阶差分均值仅为传统方法的XX%，验证了数据驱动全机设计在声爆—气动—几何光顺性上对传统分段经验方法的全面超越。

## 一、Introduction（引言）

### 1.1 SST发展背景
- 快速旅行是人类永恒追求，超声速客机提升旅行效率
- 过去数十年，下一代SST的研发持续推进

### 1.2 声爆：商业化的核心障碍
- FAA/ICAO陆上超声速飞行禁令
- 低声爆设计是下一代SST的硬需求（NASA X-59 Quesst、JAXA D-SEND等）
- 低声爆与高气动效率的设计矛盾（细长比 vs 体积效率）

### 1.3 现有低声爆构型的容量局限
- X-59、JAXA低音爆概念等载客量普遍 < 50座
- 低声爆要求细长机身 → 客舱体积受限 → 商业经济性不足
- **研究空白**：大载客量与低声爆的兼容性缺乏系统研究

### 1.4 BWB布局的潜力与挑战
- BWB提升客舱容积效率（翼身融合增加可用空间）
- 超声速BWB的气动优势（减小浸润面积）
- 现有研究集中于小型/无人构型，大载客量BWB低声爆设计可行性未知

### 1.5 JSGD反设计方法及在大BWB上的困境
- JSGD理论：等效截面积分布 → 远场声爆信号
- 标准做法：参数空间优化匹配目标面积分布
- 大BWB的根本困难：客舱体积是硬约束 → 等效截面积天然偏高 → 优化器被"压低面积"的目标驱使走向极端几何
- **传统应对**：分段优化（机翼→机身→头部），但存在三个方法论缺陷：
  - (a) 变量削减靠经验，不可迁移
  - (b) 分段假设翼-身-头可解耦，但物理上等效截面积在同站位叠加
  - (c) 工程师的隐式知识无法编码入优化程序

### 1.6 生成模型在工程设计中的潜力
- VAE/cVAE在形状生成中的已有应用概述
- 生成模型作为"搜索空间约束器"的思路：学习合理外形的低维流形
- 与传统手工约束的本质区别：合理性从数据中涌现，而非靠规则指定

### 1.7 本文目标与贡献
- **目标**：探究160座级大BWB全机低声爆设计的可行性，用数据驱动方法替代传统分段经验流程
- **贡献1**：提出cVAE驱动的全机JSGD反设计框架，以面积分布为条件、隐空间承载多解性，实现一次性全机几何生成
- **贡献2**：发展随机游走+CST参数的样本生成管线，在保证几何光顺性的前提下高效覆盖大设计空间
- **贡献3**：建立全机联合生成 vs 传统分段优化的端到端对比验证体系
- **贡献4**：给出160座SBWB的低声爆可行方案及其气动/声爆/几何综合评估

## 二、Methodology（方法）

### 2.1 CST全机参数化
- 展向M个固定站位的剖面参数化
- 每站位参数：前缘(x,z)、后缘(x,z)、CST上表面K个系数、CST下表面K个系数
- 输出向量维度：M × (4+2K)，展平为geometry向量

### 2.2 等效截面积正向计算
- 面元法近场压力场
- 沿马赫平面积分 → 等效截面积沿机身轴线的分布（condition向量，N_x维）

### 2.3 数据生成：随机游走采样
- 从光滑基准构型出发，MCMC随机游走
- 每步高斯小扰动 + 客舱体积/厚度/相邻站位差快速筛选
- 多链并行，保证设计空间覆盖
- 目标：500~2000个有效样本

### 2.4 cVAE模型设计
```
Encoder: [condition, geometry] → μ, logvar → z
Decoder: [condition, z] → geometry_recon
Loss: MSE(recon, true) + β * KL( N(μ,σ²) || N(0,I) )
```
- 隐变量维度 Z=16或32
- β-annealing训练策略：预热（β=0）→ 线性增长 → 固定β
- Skip connection：decoder中间层重新注入condition

### 2.5 候选生成与多目标选型
- 给定目标面积分布 → 采样N个z → decoder生成N个候选geometry
- 面元法验证真实面积 → 筛除面积匹配差的
- 多目标排序：PLdB ↓, 升阻比 ↑, 客舱体积 ✓, 几何光顺性 ✓
- 选型标准：面积RMSE < ε 且 PLdB最低 且 升阻比可接受

### 2.6 基准方法：传统JSGD分段优化（用于对比）
- 严格执行机翼→机身→头部分段流程
- 每段在缩减后的CST子空间内优化
- 手工约束权重由工程师经验设定

## 三、Verification Setup（验证设计）

### 3.1 验证构型
- 160座级SBWB，起飞总重约150吨，巡航马赫数1.8，高度18km

### 3.2 对比基准
- 基准构型声爆：106 PLdB（JSGD全机优化初值）
- 传统分段JSGD最优解
- X-59同等条件计算结果（参考）

### 3.3 验证指标体系

| 指标类别 | 具体指标 | 测量方法 |
|----------|---------|---------|
| 面积匹配 | 真实面积 vs 目标面积的RMSE | 面元法直接计算 |
| 声爆 | 地面PLdB | 近场面元法 + 远场传播 |
| 气动 | 巡航升阻比 L/D | SU2 Euler + 工程粘性修正 |
| 几何合理性 | 展向一阶差分均值 | 相邻站位参数差值统计 |
| 客舱体积 | 客舱可容体积 | CST解析几何计算 |
| 生成多样性 | 同条件多候选的成对欧氏距离 | 50次采样统计 |
| 计算效率 | 单次候选生成时间 vs 单次JSGD优化迭代 | 墙上时间 |

### 3.4 五层验证递进

**验证1：重建精度**
- 测试集上，给定面积 + z=μ，decoder输出的geometry与真实geometry的MSE
- 对比纯自编码器（无隐变量）→ 证明z确实承载了信息

**验证2：条件生成——面积匹配能力**
- 用未参与训练的JSGD目标面积作为condition
- 采样100个候选，计算每个的真实面积 vs 目标面积的RMSE
- 与分段JSGD优化达到同等RMSE所需迭代次数对比

**验证3：生成多样性**
- 同一目标面积，50个不同z → 50个候选geometry
- 统计成对欧氏距离的均值与方差
- 可视化：展向参数沿展向的分布曲线束（前缘x、后缘z等）

**验证4：物理合理性**
- cVAE生成的100个候选 vs 传统JSGD全机优化的100个中间解的统计对比
- 指标：展向一阶差分均值、翼型负厚度出现率、客舱体积达标率

**验证5：端到端性能——全机生成 vs 分段优化**
- cVAE候选池选出的最优构型 vs 分段JSGD最优构型
- 对比：PLdB、L/D、几何光顺性、人工干预次数
- **核心判决**：cVAE全机解在至少两个维度（PLdB + 几何合理性）上显著优于分段解

## 五、Conclusion（结论）

### 5.1 主要结论
- 大容量BWB的低声爆设计可行性得到验证：160座方案可达XX PLdB
- cVAE全机反设计框架可有效替代传统分段经验流程
- 数据驱动的合理性约束比手工规则更可靠且可迁移

### 5.2 未来工作
- 扩展数据集覆盖更多马赫数/高度工况
- 将展向曲线控制融入参数化提升生成效率
- 与总体设计框架（SUAVE）对接，实现"声爆—气动—任务"全链优化
