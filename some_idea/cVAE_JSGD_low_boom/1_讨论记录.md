## 二、核心思路的诞生

### 2.1 用户提出的初始想法

> "能否建立一个生成模型，基于CST全机参数化方法，输入目标等效截面积，直接输出对应的CST参数列表？"

### 2.2 问题的病态本质

等效截面积是三维外形沿马赫平面的投影积分（3D → 1D）。从1D面积分布反推3D外形，信息论上是**多对一**映射——无穷多种外形能产生同一条面积曲线。

JSGD优化出奇异外形的根源：优化器在数学上找到了一个匹配面积目标的方向，但这个方向在物理上不合理。"像一架飞机"从未被显式地写进优化问题。

### 2.3 确认方向：多解生成 + 后筛选

用户确认了第二种情况（一个面积对应多种合理外形），选择cVAE方案：
> 输入目标面积分布 → 采样不同隐变量z → 生成多个合理候选外形 → 多目标选型

## 三、CST全机参数化基础

### 3.1 参数化结构

飞机沿展向切为M个剖面（展向站位数固定），每个剖面存储：
- 前缘x位置
- 前缘z位置（z方向偏移，累积形成上反效果）
- 后缘x位置
- 后缘z位置
- CST系数（上表面K个 + 下表面K个）

每站位约12~14个参数，M个站位展平后约120~280维的输出向量。

### 3.2 上反角的处理

用户澄清：上反角不是单变量，而是每个展向剖面的局部z偏移（M个值），已包含在CST参数向量中。讨论结论：初始采样时z偏移保持小量级，其对马赫面截取的影响可忽略，不需要在cVAE框架中做特殊拆解。

## 四、数据集构建

### 4.1 单个样本结构

```
样本_i = {
    "condition": 等效截面积分布,   # 1D向量, 轴向离散 N_x ≈ 50~100
    "geometry":  展平参数向量       # 1D向量, 长度 ≈ M × (12~14)
}
```

### 4.2 数据生成管线

```
循环生成外形：
  1. 在CST参数空间采样 → geometry 向量
  2. 解析检验客舱体积 ≥ V_min（CST阶段即可判断，无需面元法）
  3. 不达标 → 丢弃
  4. 达标 → 参数化出完整3D外形 → 面元法算近场 → 等效截面积分布 → condition
  5. 存储 (condition, geometry)
```

### 4.3 采样策略：随机游走

**问题**：直接随机扰动CST参数，几何光顺性合格率极低（3月已反复验证）。

**方案**：基于MCMC随机游走
```
1. 从已有光滑基准构型出发（θ₀）
2. 每次从已接受池中随机选一个 θ_current
3. 高斯扰动：θ_proposal = θ_current + ε, ε ~ N(0, σ²)
   策略：每次只扰动约30%的维度，σ取各参数当前值的1%~5%
4. 快速检验：
   a. 解析算客舱体积 → 不达标拒
   b. 翼型厚度 < 0 → 拒
   c. 相邻站位前缘/后缘差值 > 阈值 → 拒（光顺性代理）
5. 三项都过 → 面元法算面积 → 存储 → 加入"已接受"池子
6. 连续拒太多 → 减小σ；一直接受 → 适当扩大σ
7. 可多链并行游走，从不同基准构型出发
```

### 4.4 数据规模估计

- 最少 500~1000 个有效样本可训练cVAE
- 2000~5000 个样本更稳定，隐空间结构更丰富
- 样本不需要都是"好设计"——各种面积分布对应各种外形，模型学到的是 P(合理外形 | 面积分布)

## 五、cVAE模型架构

### 5.1 网络结构

```
Encoder:
  input:  [condition (N_x), geometry (M×P)]  # 拼接
  hidden: 2层全连接, 256或512, ReLU
  output: μ (dim=Z), logvar (dim=Z)

Decoder:
  input:  [condition (N_x), z (Z)]
  hidden: 2层全连接, 256或512, ReLU
  中间层 skip connection: 重新拼 condition
  output: geometry_recon (M×P)
```

### 5.2 关键超参

| 参数 | 建议值 | 说明 |
|------|--------|------|
| Z（隐变量维度） | 16或32起步 | 太小→多样性不足；太大→训练困难、KL塌缩 |
| hidden_dim | 256或512 | 两层全连接足够，数据量不支持更深 |
| batch size | 64~128 | 全连接网络可用大批量 |
| β | β-annealing | 前1/3: β=0; 中1/3: β线性增加到1.0; 后1/3: β=1.0 |

### 5.3 Loss函数

```python
recon_loss = MSE(geometry_recon, geometry_true)
kl_loss = -0.5 * sum(1 + logvar - μ² - exp(logvar))
loss = recon_loss + β * kl_loss
```

β < 1（如0.1）可容忍隐空间稍不标准，换取更好的重建质量——对面积匹配精度更有利。

### 5.4 推理（生成候选）

```python
给定目标面积分布 condition_target:
  1. 采样 N_candidates 个 z ~ N(0, I)
  2. decoder(condition_target, z) → N 个 candidate geometries
  3. 对每个候选跑面元法 → 真实面积分布 + 声爆
  4. 多目标选型：面积匹配 + PLdB + 客舱体积 + 升阻比
```

### 5.5 容易踩的坑

- **数据未归一化**：CST参数、面积值、z偏移量纲不同，必须全部归一化（[0,1]或标准正态）
- **Z太大**：起步用16或32，Z=128训练极不稳定
- **验证集划分**：面积分布→几何是多对一，不同geometry可能产生相似面积。应按面积分布的相似度做train/val split，不能随机分
- **KL塌缩**：kl_loss一直为0说明忽略z、退化为普通AE。延长β=0预热或减小β目标值
- **condition被稀释**：如果N_x远小于M×P，decoder中间层需重新注入condition（skip connection）

## 六、传统JSGD实践背景（必要性论证的关键素材）

### 6.1 传统JSGD的标准分段流程

```
全机设计 → 变量太多 → 优化不动
    ↓
分段策略（靠经验决策）：
  ① 先修机翼 → 看大趋势
  ② 修机身 → 微调分布
  ③ 头匹配不上 → 单独设计头部
  
三段独立优化，段间耦合靠工程师直觉
```

### 6.2 三个方法论缺陷

**缺陷一：变量削减靠经验，不可迁移**
为什么先修机翼再修机身？换成新构型、新马赫数，策略可能完全不同。方法不可自动化。

**缺陷二：分段假设可解耦，但物理上翼-身-头是耦合的**
机翼和机身的等效截面积在同一轴向站位叠加。先修机翼定下来的目标，默认机身不会在同一站位再贡献面积。机身粗了 → 该站位超了 → 机翼工作白做。

**缺陷三：工程师的隐式知识无法被编码**
"机翼应该保持什么基本形状"——这是经验知识，无法写入优化程序，无法被他人复用。

### 6.3 传统框架的核心两难

> 要么全机优化 → 变量爆炸 → 奇异外形概率指数上升
> 要么分段可靠 → 但丢失翼身耦合 → 且依赖经验不可迁移
> 
> 这个两难在小型构型（X-59级别）上不明显，但在大BWB上被客舱体积约束急剧放大

## 七、方法的物理可解释性

### 7.1 曲线拟合应该在形状层而非参数层

用户的疑问：两个CST参数向量欧氏距离很远，但曲线形状相似。如果对CST系数做展向曲线拟合，会不会把"参数空间远但形状相似"的多样性消灭？

讨论结论：**展向曲线控制应套在几何特征量上（厚度、弯度、前缘半径），而非CST参数本身。** CST参数互相跳变只要产出的是连续且相似的翼型形状就没有问题。曲线约束在形状层保证的是"相邻展向的翼型厚度/弯度连续变化"（真正的物理光顺性），而非"相邻站位的参数值接近"（参数层的假光滑）。

### 7.2 cVAE的隐式物理合理性

训练数据本身经过光顺性和客舱筛选。模型学到的分布 P(geometry | area) 天然把"不合理外形"排除在外——不需要人工定义什么是合理外形。这是在数据中涌现的物理约束，区别于手工规则。

## 八、方法的适用范围与局限

### 适用条件
- CST参数化、展向站位固定的结构化几何表示
- 等效截面积可由正向计算（面元法/CFD）批量获取
- 设计空间中"合理外形"的流形可以被有限样本覆盖

### 当前局限
- 无法保证生成的候选**最优**，只能保证"在训练数据定义的合理区域内"
- 对训练数据覆盖范围外的面积目标，外推能力未知
- 生成质量依赖于采样策略对设计空间的覆盖程度

## 九、讨论过程中的关键决策记录

1. **放弃参数叠加作为主线**：参数叠加是线性方法的特例，cVAE是非线性扩展，能力更强
2. **不上反角单独拆出**：影响小，保持数据结构的简洁
3. **展向曲线控制不进本期核心方案**：作为后续增强项，先用随机游走撑出数据
4. **cVAE定位为"搜索空间替换"而非"端到端预测器"**：生成候选后需要面元法验证和人工选型
5. **总体设计内容留给中文小论文**：ICAS聚焦几何-气动-声爆链
