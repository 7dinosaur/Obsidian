# 汇报框架：cVAE驱动的全机JSGD低声爆反设计

> 用途：组会/PI汇报
> 时长：15—20分钟
> 结构：痛点 → 洞察 → 方案 → 预期

---

## 一、一句话概括

**传统JSGD在大BWB上被困在两难中——全机优化出奇异外形，分段优化丢耦合靠经验。我们用cVAE从数据中学习"什么是合理飞机"，一次性生成全机候选，打破这个两难。**

---

## 二、痛点是真实的

### 4月的墙

| 尝试 | 结果 |
|------|------|
| FFD全机优化 | 翼展框多 → 奇异外形 |
| 减少FFD控制框 | "不能乱动"，需要先验形状概念 |
| JSGD体积匹配 | 4m截面出现内凹曲线来规避体积 |
| 头部单独优化 | 匹配效果也不理想 |
| Laplace能量约束 | 展向/弦向能量差1-2量级，与光顺性不强相关 |
| 导数约束 | 可滤坏解，不能阻止优化器朝坏方向走 |

### 这不是调参问题，是方法论问题

传统流程图：

```
目标面积分布 → 优化器在参数空间搜索 → 匹配了...但长得不像飞机
                                              ↓
                                    加约束 → 拉回来 → 面积又不对了
                                              ↓
                                    分段（机翼/机身/头）→ 能工作了
                                              ↓
                                    但翼身耦合丢了，分段策略靠经验
```

---

## 三、核心洞察

**"像一架飞机"这个约束，靠手工写规则写不出来，但它可以被数据学到。**

> 如果一个模型见过1000个光顺合理的飞机外形，它就能在给定面积条件后，只生成那些"看起来像飞机"的解。

## 五、为什么一定比传统方法好

| 对比维度 | 传统JSGD（分段） | 本文cVAE（全机） |
|----------|----------------|-----------------|
| 翼-身-头耦合 | 人为解耦，假设成立吗？ | 数据中学到的隐式耦合 |
| 策略依赖 | 每阶段靠经验决策 | 训练后无人工 |
| 可迁移性 | 换构型重新摸索 | 换构型重新采样训练 |
| 几何光顺性 | 后验约束，不可靠 | 数据内建，生成即光顺 |
| 解的数量 | 一次一个解 | 一次一批候选，可选型 |
| 搜索空间 | 子空间之和 < 全空间 | 全机联合搜索 |

## 六、验证策略：五层递进

| 层次 | 验证什么 | 成功标准 |
|------|---------|---------|
| 1. 重建 | 模型学到geometry分布了吗 | MSE显著低于纯AE基线 |
| 2. 面积匹配 | 生成的外形匹配目标面积吗 | RMSE < 传统优化同精度所需迭代 |
| 3. 多样性 | 同一面积能出不同合理外形吗 | 成对欧氏距离方差大 |
| 4. 合理性 | 生成的外形比传统JSGD更像飞机吗 | 展向差分/负厚度率显著更低 |
| 5. 端到端 | 全机生成最优解 vs 分段最优解 | PLdB & 光顺性双重优势 |

## 十、风险与应对（一句话版）

- **cVAE训练失败**（KL塌缩）→ β-annealing + 降Z维度
- **面积匹配精度不够** → 在loss中加面积匹配项，或增大网络容量
- **最优候选不比分段好** → 论文重点转"替代手工约束 + 效率优势"
- **采样效率太低** → 多链并行 + 放宽快筛阈值
