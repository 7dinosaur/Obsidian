# 基于单元中心贪心独占映射的CFD非结构→结构化网格插值算法

## 1. 预处理阶段

**输入**：Tecplot DAT文件（FEBrick六面体单元，节点密度场）  
**输出**：目标结构化网格参数、初始化数组

1. 读取DAT头部，校验 `FEBrick` 与 `DATAPACKING=POINT`。
2. 读取全部节点坐标及节点密度值。
3. 读取单元连接表，构造所有六面体单元，对每个单元计算：
   - 几何中心  
     $$P_c=(x_c,y_c,z_c)=\frac{1}{8}\sum_{m=0}^{7}V_m$$
   - AABB包围盒  
     $$[x_{\min},x_{\max}], [y_{\min},y_{\max}], [z_{\min},z_{\max}]$$
4. 根据需求截取前段流场，构建三维均匀结构化网格：
   - 原点 `origin=(x0,y0,z0)`
   - 步长 `spacing=(dx,dy,dz)`
   - 维度 `dim=(Nx,Ny,Nz)`
5. 初始化全局数组：
   ```
   rho_target[Nx][Ny][Nz] = 0.0
   occupied[Nx][Ny][Nz] = False
   valid_mask[Nx][Ny][Nz] = 0
   ```

---

## 2. 核心循环：正向遍历所有源单元

对每个源单元 `C`（索引 `e = 0 → E-1`）执行：

### 2.1 粗匹配——中心就近寻址

- 取出单元几何中心 `P_c = (x_c, y_c, z_c)`
- 计算目标网格整数下标：
  $$
  i = \left\lfloor \frac{x_c - x_0}{dx} \right\rfloor,\quad
  j = \left\lfloor \frac{y_c - y_0}{dy} \right\rfloor,\quad
  k = \left\lfloor \frac{z_c - z_0}{dz} \right\rfloor
  $$
- 若 `i∉[0,Nx-1]` 或 `j∉[0,Ny-1]` 或 `k∉[0,Nz-1]`，则跳过该单元（`continue`）。

### 2.2 独占上锁判定

- 若 `occupied[i][j][k] == True`，则跳过该单元（`continue`）。

### 2.3 精细校验——空间相交检测

- 根据 `(i,j,k)` 计算目标网格单元的空间AABB：
  $$
  X_{t}=[x_0+i\cdot dx,\ x_0+(i+1)\cdot dx],\quad
  Y_{t}=[y_0+j\cdot dy,\ y_0+(j+1)\cdot dy],\quad
  Z_{t}=[z_0+k\cdot dz,\ z_0+(k+1)\cdot dz]
  $$
- 检测源单元AABB与目标单元AABB是否相交：
  - 不相交 → 放弃匹配，跳过该单元
  - 相交 → 进入插值流程

### 2.4 六面体线性形函数插值

- 取目标网格单元体心为采样点：
  $$
  P_t = \left(x_0+(i+0.5)dx,\ y_0+(j+0.5)dy,\ z_0+(k+0.5)dz\right)
  $$
- 求解 `P_t` 在源六面体中的局部自然坐标 `(ξ,η,ζ) ∈ [0,1]^3`（通过逆映射或牛顿迭代）。
- 计算8节点线性权重：
  $$
  \begin{aligned}
  w_0&=(1-\xi)(1-\eta)(1-\zeta),&
  w_1&=\xi(1-\eta)(1-\zeta),\\
  w_2&=\xi\eta(1-\zeta),&
  w_3&=(1-\xi)\eta(1-\zeta),\\
  w_4&=(1-\xi)(1-\eta)\zeta,&
  w_5&=\xi(1-\eta)\zeta,\\
  w_6&=\xi\eta\zeta,&
  w_7&=(1-\xi)\eta\zeta
  \end{aligned}
  $$
- 加权求和得密度：
  $$
  \rho_t = \sum_{m=0}^{7} w_m \cdot \rho_m
  $$

### 2.5 赋值与上锁

```
rho_target[i][j][k] = rho_t
occupied[i][j][k] = True
valid_mask[i][j][k] = 1
```

---

## 3. 收尾处理

- 遍历全部源单元后，`valid_mask` 即等于 `occupied`。
- `valid_mask == 0` 的区域标记为域外无效区，后续处理中屏蔽。

---

## 4. 可选轴对称柱坐标优化（旋成体场景）

若目标为轴对称流场，将直角坐标映射为柱坐标 `(x, r, θ)`：

1. 对每个源单元中心计算：
   $$
   r = \sqrt{y^2+z^2},\quad \theta = \operatorname{atan2}(z,y)
   $$
2. 径向可采用非线性幂律映射（如 `r' = r^α`）以适配锥尖加密。
3. 周向角度进行周期性取模，消除 `0/2π` 边界断裂。

坐标映射后仍沿用步骤2-3的贪心匹配与插值流程。

---

## 5. 边界与异常处理

| 异常情况 | 处理方式 |
|---------|---------|
| 单元中心下标越界 | 直接跳过该源单元 |
| AABB相交但采样点不在单元内部 | 放弃匹配，跳过 |
| 浮点数取整边界偏差 | 引入容差 `eps=1e-9` 修正 |
| 极薄边界层跨目标网格 | 优先保留流向激波结构，按贪心规则分配 |

---

## 6. 输出

- 三维密度场 `rho_target[Nx][Ny][Nz]`
- 有效掩码 `valid_mask[Nx][Ny][Nz]`

可直接接入后续纹影后处理流水线（镜像、平滑、梯度计算、导出VTI等）。
